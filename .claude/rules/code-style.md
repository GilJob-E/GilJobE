# 코드 스타일

- 함수는 짧게 — **한 가지 일만**, 20줄 이내 권장.
- 네이밍은 일관되고 의미 있게 — Python: 변수·함수 `snake_case`, 클래스 `PascalCase`, 상수 `UPPER_SNAKE`.
- 주석은 **"왜"**를 적는다("무엇"은 코드로 드러낸다). 주석 언어: **한국어**(포팅 원본 gje와 일치).
- 조기 추상화 금지 — 같은 패턴이 3번 나오기 전엔 일반화하지 않는다.
- 기존 코드의 스타일을 따른다(주변 코드처럼 읽히게). **포팅한 gje 모듈의 관용을 유지**한다(새 스타일 끼워넣지 않기).
- 타입 힌트 사용, `from __future__ import annotations`로 가볍게(gje 관례).
