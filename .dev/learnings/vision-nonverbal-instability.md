# 학습 — 젬마 비언어(시각) 채널 불안정성 (Slice 3 검증 중 발견)

> .dev = AI 작업 흔적/실험 결과. 이건 kor.mp4 풀 추론(`.dev/run_kor_inference.py`,
> 원자료 `.dev/kor_gemma_out.json`)에서 관찰한 것. 우선순위 아님 — parked.

## 무엇을 관찰했나
kor.mp4(한국어 1분 자기소개, 잘 연출된 합격 영상)로 13개 3초 윈도우 비언어 read + 16초 eval을 돌린 결과:

1. **상투구 반복** — `"미세한 입술 떨림과 약간의 긴장감이 관찰됨"`이 6개 윈도우(6-9, 9-12, 18-21, 24-27, 27-30, 30-33s)에서 거의 동일하게 반복. 매 윈도우 새 관찰이라기보다 **고정 문구로 수렴**.
2. **시각 채널 ↔ 심층 eval 자기모순** — 비언어 채널 "미소 유지"(0-3, 12-15, 33-36s) vs 심층 eval "표정: 무표정에 가까움". 실제 프레임(15s·33s)엔 또렷한 미소.
3. **라벨 보수성** — confident가 라벨셋에 있는데 13윈도우 중 **0번** 사용. 같은 침착함을 engaged + "약간 긴장"으로 읽음. (클로드는 같은 스틸을 confident로 읽음 → 모달리티/캘리브레이션 괴리.)

## 원인 가설
- **stateless per-window**(`_ask_json`가 매번 새 메시지, 히스토리 0) → baseline 비교 불가 → 정상 발화 조음을 "떨림"으로 과독.
- **greedy 디코딩(temp=0) + 프롬프트 편향**("안전하게 engaged로 때우지 마라, 긴장·불안 적극 포착") → 매번 같은 "긴장" 문구로 떨어짐.
- **1fps·3프레임/윈도우** → 미세 모션 단서 부족(vLLM 내부 ~2fps 리샘플 천장도 있음).

## 보강 옵션 (parked — 사용자 지시로 기록만)
- **옵션 A (별도 모듈)**: 입력단에 **facial-detection 병렬 레인** 추가(mediapipe FaceMesh 등, CPU). 시선 방향·깜빡임 빈도·표정 AU를 객관 수치로 뽑아 젬마 시각 채널을 교차검증/그라운딩. 멀티모달 LLM의 "느낌" 판정을 결정론적 신호로 보정.
- **옵션 B (저비용 먼저)**: 3초 윈도우 fps 1→2 + note 다양성 강제 프롬프트 → 스파이크로 효과 측정(보장 X). cf. 메모 `[[vision-nonverbal-instability]]`.
- 착수 시 PLAN에 슬라이스로 편입. 음성 기반 vocal 비평(단조 톤 등)은 별개로 잘 작동하므로 시각만 보강 대상.
